# Acumatica Azure Staging Environment

## Summary

The Acumatica Azure Staging Environment is a cloud-infrastructure and ERP staging project for Acumatica 2022 R2. It covers Azure infrastructure, Windows Server, SQL Server, IIS, approved snapshot restoration, customization publishing, controlled access, testing support, and environment handoff.

## Problem or goal

ERP customization and upgrade work needed an isolated environment that was representative enough for testing while remaining controlled, repeatable, and safe to hand over to project participants. Version alignment across Acumatica, the database, and published customizations was important, and public documentation could not expose operational values or private data.

## Ace's role

Ace publicly describes his role as developer and technical coordinator responsible for environment setup, restoration and publishing steps, access coordination, testing support, and handoff documentation. He coordinated the Azure, Windows, SQL Server, IIS, and Acumatica sequence, restored approved snapshots, published required customizations, and supported validation and handoff.

## Solution

The environment was built as a documented dependency sequence with prerequisites and checkpoints. Infrastructure readiness, database and application restoration, customization publishing, access confirmation, user validation, and owner-facing handoff were treated as separate stages so problems could be isolated and the resulting environment could be used safely.

## Features or capabilities

- Microsoft Azure virtual infrastructure for a controlled staging workload.
- Windows Server, SQL Server, and IIS prerequisites for Acumatica 2022 R2.
- Approved snapshot restoration and customization-publishing workflow.
- Infrastructure and service-readiness checks.
- Application access and restored-data verification using approved test procedures.
- Access coordination, role-based validation, testing support, and environment handoff.

## Technologies

- Microsoft Azure
- Acumatica 2022 R2
- Windows Server
- SQL Server
- IIS

## Skills demonstrated

This project demonstrates cloud infrastructure work, ERP staging, deployment sequencing, database and web-server configuration, customization publishing, testing support, access coordination, technical documentation, stakeholder handoff, and technical project leadership.

## Results or current status

The result documented in the portfolio is a controlled Acumatica 2022 R2 staging environment prepared for isolated testing, customization validation, and approved stakeholder access. It is not presented as a production deployment or a performance benchmark.
